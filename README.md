## ✨ Features

- 🔐 Firebase Authentication
- 🎥 Multi-source Video Player
- ❤️ Watchlist Synchronization
- ⏱ Continue Watching
- 🔎 Live Search & Filters
- 👤 User Profiles
- 🛠 Admin Dashboard
- 📊 Bulk Movie Upload (Excel / JSON)
- 📱 Fully Responsive UI

## 🚀 Getting Started

```bash
git clone https://github.com/Shiva134-ui/StreamX.git
cd StreamX
```

Run using:

- VS Code Live Server
- Python HTTP Server
- `npx serve`
